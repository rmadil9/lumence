# Learning Log

One line per concept I met and what it means. My proof I am not vibe coding.

| Concept | Where it bit me | One-sentence definition |
|---|---|---|
| Descope ladder | Kickoff: chosen scope came to ~18–19 days against a fixed 15-day deadline | A pre-agreed, ordered list of cuts to make when a fixed deadline meets excess scope, decided while calm rather than on the last day. |
| Wayland focus isolation | Kickoff: whole-day app tracking on Ubuntu GNOME | Wayland deliberately gives no application the ability to query which window has focus, so desktop activity tracking needs a compositor-side extension rather than a client-side query. |
| Seam | Kickoff: deferring browser-tab tracking and real X API posting | An interface placed at a boundary so a deferred implementation can drop in later without changing callers. |
